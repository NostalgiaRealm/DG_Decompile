# MS/arm64x/D3D9.dll

Direct3D 9 API front door. `Direct3DCreate9` and `Direct3DCreate9Ex` lead toward object creation. The `D3DPERF_*` exports form a separate group and can share stub implementations; check addresses before treating each name as a distinct feature. The ARM64X binary needs its separate loader views.

## Identity

- Machine/format: ARM64X hybrid, PE32+.
- Preferred image base: `0x180000000`; entry RVA: `0x103198`.
- Supplied SHA-256: `d213eea2478b312b9c5913759e301d9aeb3fb3ea9c05f8cc7ae8e592525dd21d`.
- Prepared SHA-256: `d213eea2478b312b9c5913759e301d9aeb3fb3ea9c05f8cc7ae8e592525dd21d`.
- Packing result: not packed with UPX (UPX test).
